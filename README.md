SISTEMA ESPECIALISTA PARA SUGESTÃO DE PAPEL EM MMORPGs

Prova de Conceito — Tank, Healer e DPS



Esse projeto é um sistema especialista destinado a auxiliar jogadores iniciantes de MMORPGs (Jogo de interpretação de personagens online em massa para multijogadores, 
do inglês Massively Multiplayer Online Role-Playing Game) na escolha entre os papéis de Tank, Healer e DPS, os 3 estilos de papéis mais usados. 
O sistema apresenta situações hipotéticas relacionadas a combates e coleta as respostas do usuário. A partir dessas respostas, 
regras da base de conhecimento associam características de atuação às funções disponíveis e calculam um índice de compatibilidade para cada papel. 
Ao final, o sistema apresenta o papel com maior compatibilidade e uma justificativa baseada nas características identificadas. 
O usuário poderá realizar uma nova avaliação caso deseje comparar o resultado.

Escopo da Prova de Conceito: três papéis, dez perguntas, pontuação baseada em regras e possibilidade de refazer a avaliação.
Definições para papéis: Tank é o papel que possui pouco dano, mas consegue puxar a atenção dos inimigos, tendo a maior defesa dos 3 papéis agindo como um tanque de transporte. Healer é o papél que possui defesa baixa e dano baixo, mas consegue recuperar a saúde dos outros aliados, até mesmo recuperando um aliado nocauteado. DPS vem do conceito Damage per Second (Dano por Segundo), que também possuí pouca defesa, mas grande capacidade de dano, sendo a fonte de o quão rápido uma equipe consegue lidar com inimigos.


Dentro desse Git temos o arquivo python do projeto e um executável na pasta dist do mesmo código já compilado para realização de testes.
